# WorkClock — Fresh Redesign Directions (V3)

Drei eigenstaendige visuelle Richtungen fuer den "Heute"-Screen, alle im selben Datenzustand
(Montag 3. August, am Arbeiten, 65 %, Restzeit 2:48, Feierabend 17:34), damit sie sich fair
vergleichen lassen. Jede Richtung zieht ihr Vokabular aus einem realen Zeitmess-Instrument statt
aus einer generischen Farbpalette.

## Richtungen

1. **Anzeigetafel** — Splitflap-Ziffern und ein Bahnhofs-Fahrplan. Dunkles Signage-Board,
   mechanische Monospace-Ziffern in Amber, Ereignisse als Fahrplanzeilen mit Punktlinien.
2. **Ledger** — gruenes Kolumnenpapier, tintenblauer Text, roter Eintragsstempel. Der Tag wird
   wie ein gebuchter Stundenzettel dargestellt, jede Zeile ein Beleg.
3. **Instrument** — ein Stoppuhr-Zifferblatt mit Skalenstrichen und Bogenanzeige, Halbrund-Gauges
   statt Kacheln, der Tagesverlauf als Massband mit Pins statt Liste.

Alle drei sind bewusst als eigene Welt gestaltet (kein gemeinsames Hell/Dunkel-Schema) — das ist
eine Entscheidung fuer diese Vergleichsrunde, kein Versaeumnis. Sobald eine Richtung (oder eine
Mischung) gewaehlt ist, folgt die Ausarbeitung von Kalender, Einstellungen und Watch-Companion
sowie die Definition von Light/Dark-Varianten fuer das produktive Compose-Theme.

## Datei

`index.html` kann direkt im Browser geoeffnet werden (verlinkt `styles.css`).
